# PlzLockedIN — Claude Code 구현 인수인계
작성일: 2026-11-02  
상태: 디자인 방향 및 프로토타입 제안. 아래 변경은 아직 저장소 앱에 구현되지 않았다.

## 1. 작업 지시
기존 앱을 먼저 읽고 아래 우선순위로 점진적으로 개선한다. 프레임워크 교체나 전면 재작성 없이 기존 HTML/CSS/JavaScript, 저장 스키마, 오프라인 기능을 활용한다.
1. 저장 안정성 보강
2. 한 줄 세션 시작
3. 압축 집중 화면
4. 짧은 돌아보기

완료 보고에는 변경 이유, 테스트 결과, 남은 제약을 구분한다. 사용자 데이터와 기존 마이그레이션·백업·병합·되돌리기를 보존한다.

## 2. 핵심 가치
“알아차린 순간, 하던 일로 돌아가기 쉽게 한다.”

- 복귀 우선: 다음 행동 하나를 명확하게 보여준다.
- 설명할 의무 없음: 버튼 한 번으로 기록 완료. 상세 입력은 선택이다.
- 평가 없는 관찰: 기록 수를 산만함, 성공, 집중력 점수로 해석하지 않는다.
- 안전하게 맡기기: 궁금증을 잃을 걱정 없이 짧게 보관한다.
- 앱 체류시간을 늘리는 설계를 하지 않는다. 스트릭, 배지, 점수, 축하 애니메이션, 경쟁, 자동 알림은 추가하지 않는다.

## 3. 채택한 디자인 시스템
최종 방향은 저장소의 파스텔 핑크 테마다. 이전 대화의 세이지 초록 대안은 채택하지 않는다.

| 토큰 | 라이트 값 | 용도 |
| --- | --- | --- |
| --bg | #f8f5f4 | 전체 배경 |
| --surface | #ffffff | 카드, 기본 표면 |
| --surface-2 | #f3eeed | 보조 표면 |
| --text | #2d2829 | 본문 |
| --muted | #645c5e | 보조 설명 |
| --border | #e8dfdf | 구분선 |
| --accent | #f3d3da | 주 행동 배경 |
| --accent-ink | #3d2329 | 주 행동 글자 |
| --accent-soft | #faeaee | 복귀 안내 |
| --accent-line | #e6b9c4 | 강조 테두리 |
| --focus | #a3485d | 키보드 포커스 |

- 기존 styles.css의 토큰과 다크 모드 값을 우선 재사용한다.
- 8px 간격 체계, 카드 모서리 16px, 입력·버튼 12px, 약한 그림자.
- 본문 16px, 보조 설명은 가급적 14px, 제목 20–24px. 장식 영문과 과도한 자간은 사용하지 않는다.
- 주 버튼과 입력의 터치 영역은 최소 44px. 명확한 포커스와 충분한 명도 대비를 유지한다.
- 그림·사진·마스코트·장식 아이콘을 추가하지 않는다.
- 색만으로 상태나 통계 의미를 전달하지 않는다. 기록 많음/적음에 빨강·초록 평가를 붙이지 않는다.
- 원본 UI 이미지의 여백과 미묘한 농도는 참고다. 작은 글자, 잘못된 문구, 임의 상태점 등 생성 이미지의 세부 오류를 복제하지 않는다.

## 4. 세 화면의 구조와 동작

### 01 — 세션 시작
목표: 한 줄만 정하고 시작하기.

위에서 아래 순서:
1. 헤더: PlzLockedIN / 시작 전
2. 제목: “돌아오면 무엇부터 할까요?”
3. 입력 라벨: “돌아왔을 때 첫 행동”
4. 입력 예시: “강의 화면에서 다음 설명 듣기”
5. 전체 너비 핑크 주 버튼: “이 행동으로 시작”
6. 조용한 보조 동작: “최근 작업 이어하기”
7. 기본 접힘: “추가 정보 · 선택”
8. 하단 낮은 강조 동작: “세션 없이 기록하기”

추가 정보 안에 기존 일 종류, 하는 일, 지금 위치 필드를 둔다. nextAction만으로 시작 가능하도록 한다. 빈 값은 세션 없이 기록하는 흐름으로 안내하며 유령 세션을 만들지 않는다.
최근 작업은 실제 이전 세션이 있을 때만 표시한다. 이어하기는 이전 세션의 기준점을 재사용하는 새 세션을 만들며, 종료된 세션을 다시 활성화하지 않는다.
세션 없이 기록도 즉시 저장, 되돌리기, 선택 메모를 지원한다. 돌아갈 행동이 없을 때는 “하던 일의 다음 한 단계” 같은 짧은 기본 안내를 사용한다.

### 02 — 압축 집중
목표: 작은 화면에서 알아차림 기록 → 원래 작업 복귀.

위에서 아래 순서:
1. 헤더: PlzLockedIN / 집중 중
2. 보조 라벨: “지금 돌아갈 첫 행동”
3. 가장 먼저 읽히는 행동: “강의 화면에서 다음 설명 듣기”
4. 가장 큰 핑크 버튼: “아차!” / 보조 문구 “지금 알아차렸어요”
5. 기록 후 같은 위치의 짧은 확인: “14:18 기록했어요”
6. 짧은 복귀 안내: “다음 한 문장부터 이어가세요.”
7. 보조 동작: “생각 한 줄 맡기기”
8. 하단: “돌아갈 행동 수정” / “집중 마치기”

- 기본 화면에 경과시간, 그래프, 최근 기록, 기록 수, 보관함 목록을 노출하지 않는다.
- 버튼을 누른 시각에 즉시 저장하고 모달을 열지 않는다. 기존 800ms 중복 방지를 보존한다.
- 기존 6초 상태 메시지와 30초 무입력 상세 닫힘 정책을 활용한다. 입력 중 강제 종료나 초 단위 카운트다운은 없다.
- “생각 한 줄 맡기기”는 사용자가 선택할 때만 입력을 펼친다. 입력한 생각은 자동 저장한다.
- 메모 저장 후 “보관하고 하던 일로 돌아가기”로 입력을 접고 첫 행동을 다시 보여준다.
- “돌아갈 행동 수정”은 현재 세션의 nextAction을 인라인 편집한다. 새 세션 시작 화면으로 보내거나 세션을 종료하지 않는다.
- 방금 기록의 되돌리기는 보조 동작으로 보존한다.
- 집중 중 통계·보관함·데이터 탐색 잠금을 유지하되, “집중 마치기”로 언제든 해제 가능하다.
- 저장 실패 시 백업은 집중 잠금과 무관하게 접근할 수 있는 비상 동작으로 제공한다.
- 압축은 먼저 반응형 웹 화면으로 구현한다. 전역 단축키, 항상 위 창, 트레이, 데스크톱 패키징을 이 작업에 포함하지 않는다.

### 03 — 짧은 돌아보기
목표: 관찰 하나와 다음 실험 하나만 읽고 종료하기.

위에서 아래 순서:
1. 헤더: PlzLockedIN / 돌아보기
2. 제목: “이번 기록을 가볍게 살펴봐요”
3. 최근 기록 분포: 날짜와 횟수의 작은 중립적 목록
4. 관찰 카드 하나
5. 다음에 해볼 작은 실험 카드 하나
6. 접힘: “맡겨둔 생각”
7. 접힘: “자세한 기록·백업”
8. 전체 너비 핑크 주 버튼: “다음 집중 시작하기”
9. 낮은 강조 동작: “오늘은 여기까지”

관찰 예시:
- 사실: “검색하러 갔다고 4번 남겼어요.”
- 한계: “선택해서 적은 기록만의 요약이에요. 원인을 알 수는 없어요.”
- 실험: “궁금한 검색어를 맡기고, 쉬는 시간에 찾아보기.”
- 카드 내부 보조 버튼: “다음 세션에서 해보기”

위 숫자·요일·시간은 전부 시안 예시다. 프로덕션 데이터로 하드코딩하지 않는다.
기록이 없는 날은 “미기록”으로 표현한다. 0건을 완벽한 집중으로 표현하지 않는다.
근거가 부족하면 관찰·추천 카드를 숨기고 “아직 관찰 중이에요”를 보여준다.
현재 15건·3일 조건은 구현상의 표시 기준이지 검증된 정확도 기준이 아니다. “15/15” 등의 수집 진행률은 제거한다.
기존 상세 통계는 삭제하지 않고 접거나 기존 화면으로 연결한다. 기본 화면의 인사이트는 하나로 제한한다.
실험 선택은 실제로 다음 세션에 유지·표시되도록 구현하고, 단순 성공 토스트만 보여주는 죽은 버튼을 만들지 않는다. 최소한의 선택 ID 저장이 필요하면 기존 호환성을 보존하며 별도 설정 또는 선택적 필드를 사용한다.
“오늘은 여기까지”는 종료 상태를 표시한다. 브라우저가 창을 닫았다고 거짓 표시하지 않는다.

## 5. 우선 해결할 저장 안정성
아래는 이전 소스 검토에서 발견한 경로다. 최신 브랜치에서 다시 확인하고 재현 테스트를 먼저 작성한다.

### 작성 중 메모
js/app.js의 thoughtInput 입력은 타이머만 갱신하고, 실제 저장은 commitThought() 시 수행됐다. 제출 전 새로고침·창 닫기로 유실되지 않도록 짧은 지연 자동저장 및 필요한 최종 flush를 구현한다. 종료 이벤트만 믿지 않는다.

### 저장 실패와 성공 문구
commitThought()가 persist() 실패를 성공으로 반환하지 않게 한다. 일반 기록 버튼의 flashButton() 등 모든 저장 표시도 실제 영구 저장 결과와 일치시킨다.
저장 불가 시 임시 메모리 상태와 영구 저장을 명확히 구분하고, 입력은 유지하며 백업 경로를 제공한다.

### 손상 데이터
js/store.js의 load()는 파싱 오류 시 empty()를 반환했다. 오류 후 빈 상태를 기존 키에 덮어쓰지 않도록 한다. 손상 원본을 보존하고 복구/원본 다운로드/별도 시작 경로를 제공한다. 정상 데이터로 자동 간주하지 않는다.

## 6. 변경이 닿는 곳
- index.html: 기본/접힘 구조, 세 화면의 콘텐츠 계층
- styles.css: 기존 토큰 재사용, 압축 레이아웃, 모바일, 다크 모드, 포커스
- js/app.js: 시작/이어하기/인라인 수정/기록/메모 저장/종료/돌아보기
- js/store.js: 손상 데이터 보호, 저장 실패, 필요한 최소 설정 보존
- js/stats.js: 기존 통계 의미 유지, 기본 인사이트 하나 선택
- tests/store.test.mjs, tests/stats.test.mjs, tests/e2e.mjs: 바뀐 계약과 회귀 검증
- sw.js: 변경 파일의 오프라인 업데이트가 정상 반영되는지 확인
- README.md: 새 시작 흐름과 실제 제약만 갱신

기존 스키마와 원본 기록을 보존한다. 리포트 수치나 복귀 여부를 추정해서 저장하지 않는다. 단축키 A/한글 입력 보호, JSON/CSV 내보내기, 병합, 되돌리기, 이전 데이터 마이그레이션을 유지한다.

## 7. 완료 조건
- [ ] 한 줄 입력으로 세션 시작. 추가 정보는 기본 접힘.
- [ ] 세션 없이도 원탭 기록 가능.
- [ ] 입력 중 메모가 새로고침 후 유지됨.
- [ ] 저장 실패 시 성공 표시 없음. 원본과 입력 유지, 백업 가능.
- [ ] 손상 데이터가 새 기록으로 덮이지 않음.
- [ ] 압축 화면에서 첫 행동과 기록 버튼을 쉽게 찾을 수 있음.
- [ ] 첫 행동 수정이 기존 활성 세션에서 작동함.
- [ ] 통계 탐색 잠금과 사용자 주도 종료가 함께 작동함.
- [ ] 기본 돌아보기는 관찰 하나·실험 하나. 미기록/근거 부족 상태 정확.
- [ ] 선택한 실험이 다음 세션에 실제 유지됨.
- [ ] 예시 통계가 사용자 데이터와 섞이지 않음.
- [ ] 375px 모바일/작은 데스크톱 창/다크 모드에서 넘침·대비·포커스 검증.
- [ ] 원탭, 되돌리기, 중복 방지, 마이그레이션, 백업·병합, 오프라인 회귀 확인.

검사 명령:
~~~powershell
node --test tests/stats.test.mjs tests/store.test.mjs
node tests/e2e.mjs
~~~
E2E가 Playwright 미설치로 SKIP되면 PASS로 보고하지 않는다.

## 8. 시안 출처와 구현 시 주의
내장 imagegen으로 세 화면이 나란히 놓인 고해상도 이미지 시안을 생성했다. 아래는 최종 생성 프롬프트의 구현용 요약이다.

> Production-ready Korean UI mockup for PlzLockedIN, three sequential screens: session start, compact focus, brief review. Warm neutral background, white surfaces, pastel pink primary actions, dark readable Korean sans-serif text, restrained 16px rounded cards, subtle shadows, 8px spacing, generous touch targets. Preserve the above screen hierarchy. No photos, illustrations, mascot, gamification, countdown, noisy dashboard, or elapsed timer in focus view.

이미지는 방향 참고이며 위 명세가 동작과 문구의 기준이다. 원격 Claude Code에서 접근 불가능한 개인 로컬 경로는 의존하지 않는다.
텍스트 명세만으로 구현 가능하도록 색상, 화면 계층, 동작, 예외 상태를 이 문서에 완결적으로 기술했다. 이미지 파일과 인터랙션 프로토타입은 이 커밋에 포함하지 않았다.
