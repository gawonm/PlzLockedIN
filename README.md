# 🟩 집중 트래커 (Focus Tracker)

딴생각을 **알아차린 순간 1초 만에** 기록하는 성인 ADHD용 집중 로그 웹앱(PWA)입니다.
무드 트래커처럼 기록이 픽셀로 쌓이고, 데이터가 모이면 나만의 집중 패턴을 규칙 기반으로 분석해 줍니다.

> 수업을 듣다가 딴생각 → 따라가서 검색 → 돌아오면 앞 내용을 놓침 → 따라가기 버거워서 또 딴생각…
> 이 루프를 **의지가 아니라 시스템으로** 끊기 위한 도구입니다.

## 바로 실행하기

빌드나 설치 과정이 없습니다.

```bash
cd focus-tracker
```

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 더블클릭해서 열어도 동작하지만, 오프라인 지원(PWA)은 http(s)로 열었을 때만 켜집니다.

- **폰에서 쓰기**: GitHub Pages 같은 곳에 `focus-tracker/` 폴더를 올린 뒤, 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.
- **노트북에서 쓰기**: 브라우저 탭 하나를 고정해 두고, 딴짓을 알아차리면 그 탭에서 `Space`를 누르세요.

## 사용법 (30초)

1. **⏱ 지금** 탭에서 "수업"을 고르고, 필요하면 복귀 앵커(예: `슬라이드 12`)를 적은 뒤 **집중 시작**을 누릅니다.
2. 딴생각이 떠오르면 상황에 맞는 버튼을 누릅니다.
   | 상황 | 버튼 | 단축키 |
   |---|---|---|
   | 떠올랐지만 **아직 안 갔음** | 🅿️ 주차하기 | `P` |
   | **이미 다녀온 뒤** 알아차림 | ↩️ 아차, 다녀왔다 | `Space` / `A` |
3. 작은 시트가 뜹니다. 카테고리나 메모는 **선택 사항**이고, 8초 뒤 자동으로 닫힙니다(`Enter`를 누르면 바로 닫힘).
4. 화면에 "수업(으)로 돌아가기 · 📍 슬라이드 12"가 잠깐 표시됩니다. 하던 일로 돌아가세요.
5. 세션을 끝낸 뒤 🅿️ 주차장에서 적어 둔 생각을 한 번에 처리하고, 📊 리포트에서 패턴을 확인합니다.

## "기록이 또 다른 딴짓이 되는 것"을 막는 장치

| 장치 | 왜 필요한가 |
|---|---|
| **원탭 즉시 저장** | 버튼을 누른 순간 시간이 저장됩니다. 그 뒤의 입력은 모두 덤입니다. |
| **8초 카운트다운 시트** | 기록 화면에 오래 머물지 못하게 합니다. 타이핑 중에는 기다려 주지만 최대 30초가 지나면 강제로 닫힙니다. |
| **주차(🅿️) vs 아차(↩️)** | "가기 전에 붙잡기"를 따로 기록합니다. 생각을 적어 두면 지금 당장 해야 한다는 충동이 줄어듭니다. 성인 ADHD 인지행동치료의 *distractibility delay* 기법을 적용했습니다. |
| **복귀 앵커** | 기록 직후 "어디로, 어디까지" 돌아갈지 크게 보여 줍니다. 놓친 부분을 따라잡다 또 이탈하는 루프를 줄이기 위한 장치입니다. |
| **세션 중 잠금** | 집중 중에는 트래커, 주차장, 리포트를 볼 수 없습니다. 통계를 구경하거나 주차한 생각을 다시 꺼내 보는 일을 막습니다. |
| **정리는 나중에** | 분류나 메모 수정은 세션이 끝난 뒤 정리함에서 합니다. |

## 화면

- **🟩 트래커**
  - *Month in Pixels*: 날짜 × 시간대별 흔들림 횟수를 보여 줍니다. 어느 시간대에 무너지는지 한눈에 볼 수 있습니다.
  - *Year in Pixels*: 하루 상태를 5단계 색으로 보여 줍니다. 기준은 세션 1시간당 흔들림 횟수입니다.
- **🅿️ 주차장 / 🗂 정리함**: 주차한 생각을 처리하고, 최근 기록 50개의 분류와 메모를 고칠 수 있습니다.
- **📊 리포트**: 기록이 20건 이상, 3일 이상 쌓이면 열립니다. 그 전에는 데모 데이터로 미리 볼 수 있습니다.
  - 지표: 주차 성공률, 집중 지속 시간(중앙값), 세션 1시간당 흔들림, 세션 시작 후 첫 흔들림까지 걸린 시간, 시간대·요일·카테고리 분포
  - 규칙 기반 제안: 예를 들어 "궁금증이 40% 이상이면 → 궁금한 건 주차해 두고 쉬는 시간에 몰아서 검색하기"

## 데이터와 개인정보

- 모든 데이터는 **이 브라우저의 localStorage에만** 저장됩니다. 서버로 전송되지 않습니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 가끔 **JSON 백업**을 받아 두세요.
- CSV는 엑셀이나 pandas 분석용이고, JSON은 용어 설명(glossary)과 시간대 정보가 포함된 자기설명형 형식이라 LLM에 바로 넣기 좋습니다.

```
sessions: [{ id, label, anchorNote, startAt, endAt }]
events:   [{ id, sessionId, ts, type: 'park'|'return', category, note, durationBucket, resolved }]
```

## 설계 메모 (통계)

- **집중 지속 시간** = 세션 시작 → 첫 흔들림, 흔들림 → 다음 흔들림 사이의 간격입니다.
  마지막 흔들림 → 세션 종료 구간은 **중도절단(censored)** 데이터라서 제외했습니다. 포함하면 "그냥 끝난 시간"이 섞여 실제보다 길게 나옵니다.
  평균 대신 **중앙값**을 쓰는 이유는 가끔 생기는 아주 긴 구간에 결과가 끌려가지 않게 하기 위해서입니다.
- **시간대별 빈도**는 횟수가 아니라 "세션 1시간당 횟수"입니다. 그 시간대에 집중을 많이 했다고 흔들림이 많아 보이는 착시를 막기 위해서입니다.
  노출 시간이 30분 미만인 시간대는 신뢰도가 낮아 제외합니다.
- **한계**: 알아차리지 못한 딴짓은 기록되지 않습니다(자기보고 편향). 그래서 "주차 성공률"과 "흔들림 횟수"는 **알아차림 능력**이 좋아질수록 오히려 늘 수도 있습니다. 숫자 하나만 보지 말고 추세와 함께 보세요.

- **맥락 변수 추가**: 수면, 복약 시간, 카페인 등을 기록해서 집중도와의 상관관계를 봅니다.
