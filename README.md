# PlzLockedIN — 집중 트래커 (Focus Tracker for ADHD)

주의가 흐트러진 걸 **알아차린 순간 버튼 한 번**을 누르고, **원래 하던 일로 바로 돌아가게** 돕는 로컬 우선 PWA입니다.

> 목표는 집중력을 강제로 높이는 것이 아닙니다. 기록하는 부담을 거의 없애고, 돌아갈 곳을 바로 보여 주는 것입니다.
> 판단 기준: "이 앱에 오래 머무르게 하는가?"가 아니라 **"원래 하던 일로 빨리 돌아가게 하는가?"**

## 실행 (Windows PowerShell)

처음 한 번만 받습니다.
```powershell
cd $HOME
git clone https://github.com/gawonm/PlzLockedIN.git
```

실행할 때마다:
```powershell
cd $HOME\PlzLockedIN
git pull
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 빌드나 설치는 필요 없습니다. `index.html`을 더블클릭해도 동작하지만, 오프라인 지원은 http로 열었을 때만 켜집니다.

> 이전 저장소(`focus-app/focus-tracker`)에서 쓰던 기록은 **주소(포트)가 같으면** 그대로 보입니다. 기록은 저장소가 아니라 브라우저의 `http://localhost:8000` 주소에 저장되기 때문입니다. 혹시 안 보이면 이전 폴더에서 서버를 띄워 데이터 탭에서 JSON 백업을 받은 뒤, 새 폴더에서 가져오기(병합)하세요.

## 사용 흐름 (세 화면)

**01 시작 전**: "돌아오면 무엇부터 할까요?"에 **돌아왔을 때 첫 행동** 한 줄만 적고 **이 행동으로 시작**을 누릅니다.
- 하는 일, 지금 위치, 일 종류는 `추가 정보 · 선택`에 접혀 있습니다.
- 첫 행동이 비어 있으면 세션을 만들지 않습니다. 정하기 어려우면 **세션 없이 기록하기**를 쓰세요.
- 이전 세션이 있으면 **최근 작업 이어하기**로 같은 첫 행동을 가진 *새* 세션을 시작합니다(끝난 세션을 되살리지 않습니다).

**02 집중 중**: 화면에는 *지금 돌아갈 첫 행동*과 **아차!** 버튼만 크게 보입니다. 경과 시간, 그래프, 기록 수는 보여 주지 않습니다.
- 아차!(또는 `A`)를 누르면 누른 시각이 바로 저장되고, 같은 자리에 `14:18 기록했어요 · 위의 첫 행동부터 이어가세요.`가 6초 동안 떴다가 사라집니다.
- 필요할 때만: `생각 한 줄 맡기기`(입력하는 즉시 자동 저장) · `자세히` · `되돌리기`
- 아래쪽의 `돌아갈 행동 수정`은 지금 세션의 첫 행동만 바꾸고, `집중 마치기`는 언제든 누를 수 있습니다.
- 집중 중에는 탭(보관함·패턴·데이터)이 숨겨집니다.

**03 돌아보기**: 집중을 마치면 짧게 봅니다.
- 최근 7일 기록 수(기록 없는 날은 "미기록")
- **관찰 하나**(사실과 해석의 한계)와 **해볼 실험 하나**
- 실험에서 `다음 세션에서 해보기`를 누르면, 다음 시작 화면과 집중 화면에 그 실험이 표시되고 새 세션에 실험 ID가 기록됩니다.
- 근거가 부족하면 "아직 관찰 중이에요"만 보여 줍니다(표시 기준: 기록 15개·3일 이상. 정확도를 보장하는 기준은 아닙니다).
- `맡겨둔 생각`, `자세한 기록·백업`은 접혀 있습니다. 자세한 통계는 기존 **패턴** 탭에 그대로 있습니다.
- `다음 집중 시작하기` 또는 `오늘은 여기까지`로 끝냅니다. "오늘은 여기까지"는 종료 상태만 표시하고, 창을 닫지는 않습니다.

## 저장 안정성
- **입력 중인 생각**은 입력 후 0.4초 뒤 자동 저장되고, 창을 숨기거나 닫을 때도 한 번 더 저장합니다. 제출 전에 새로고침해도 남습니다.
- **저장에 실패하면** "기록했어요" 같은 성공 문구를 띄우지 않습니다. 화면 위 안내에서 바로 **JSON 백업**을 받을 수 있고(집중 중에도 가능), 저장하지 못한 입력은 지우지 않고 그대로 둡니다.
- **저장 데이터가 손상돼** 읽을 수 없으면 빈 데이터로 간주하지 않고 저장을 멈춥니다. 원본은 덮어쓰지 않습니다. 그다음 세 가지 중에서 고릅니다.
  - `손상 원본 내려받기`
  - `백업 파일로 복구`
  - `원본 보관하고 새로 시작`: 원본을 `focusTracker.corrupt.<시각>` 키로 따로 보관한 뒤 새로 시작합니다.
- 일부 항목만 읽을 수 없으면 그 항목을 건너뛰고, 원본을 먼저 따로 보관합니다.

## 기록 때문에 딴짓이 생기지 않게 하는 장치
| 장치 | 내용 |
|---|---|
| 원탭 즉시 저장 | 모달이 없고 입력을 강요하지 않습니다. 800ms 안의 중복 클릭은 무시하고, 그 뒤에 누르면 새 기록이 됩니다 |
| 첫 행동 1개 | 집중 화면 맨 위에 돌아갈 행동 하나만 보여 줍니다 |
| 자동으로 사라짐 | 상태 영역은 6초 뒤 사라지고, 생각 입력과 상세 시트는 30초 동안 입력이 없으면 닫힙니다(내용은 이미 저장됨). 초 단위 카운트다운은 없습니다 |
| 압축 화면 | 집중 중에는 탭, 통계, 기록 수, 경과 시간을 숨깁니다 |
| 게임화 없음 | 스트릭, 점수, 배지, 축하 애니메이션, 알림이 없고, 빨강/초록으로 평가하지도 않습니다 |

## 패턴 화면 읽는 법 (중요)
- 기록 수는 **알아차리고 누른 횟수**입니다. 실제로 주의가 흐트러진 횟수가 아닙니다.
- 기록이 없다고 집중했다는 뜻은 아닙니다. 그래서 "집중 지속 시간"은 계산하지 않습니다.
- **시간당 비율**은 직접 종료한 5분~6시간 세션에서만 계산합니다. 12시간 넘게 열려 있던 세션은 자동으로 닫고 계산에서 뺍니다.
- **기록 사이 간격**은 같은 세션(세션이 없으면 같은 날) 안에서 앞 기록과의 간격입니다. 이탈이 얼마나 길었는지(지속시간)가 아닙니다.
- 5분 이내로 이어진 기록은 "연쇄 **가능성**"으로만 표시하고, 같은 이탈인지 단정하지 않습니다.
- 인사이트는 기록이 15개 이상이고 3일 이상 쌓인 뒤에만 보여 줍니다. 형식은 **관찰된 사실 → 해석의 한계 → 해 볼 작은 전략**입니다. 진단이나 치료 효과를 주장하지 않고, 상관관계를 인과관계로 말하지 않습니다.
- 날짜와 시간대는 앱을 여는 기기의 로컬 타임존 기준으로 표시합니다. 각 기록에는 당시 타임존(`tz`, `tzOffsetMin`)이 함께 저장됩니다.

## 데이터
- 저장 위치: 이 브라우저의 `localStorage` 키 `focusTracker.v2`. **서버로 전송하지 않습니다.**
- 브라우저나 기기마다 따로 저장되며, 브라우저 데이터를 지우면 사라집니다. 데이터 탭에서 JSON 백업을 받아 두세요.
- 1차 버전 데이터(`focusTracker.v1`)는 처음 열 때 v2로 자동 변환됩니다. 원본은 지우지 않고 그대로 남습니다. "전체 삭제"를 실행할 때만 함께 지워집니다.
- 가져오기는 v1과 v2 JSON을 모두 받습니다. 기본은 **id 기준 병합**이고, 대체는 확인을 거쳐야 합니다.

```
sessions: { id, taskType, task, location, nextAction, experimentId?, startAt, endAt,
            endReason: manual|stale-closed, tz, tzOffsetMin, createdAt, updatedAt }
events:   { id, sessionId, ts, tz, tzOffsetMin, source: one-tap|migrated, taskType,
            thought, activity, trigger, returned: yes|no|unknown, note,
            keepForLater, laterDone, chainLink(예약), legacy?, createdAt, updatedAt }
settings: { experiment: { id, text, chosenAt } | null }   ← 선택한 실험 (선택적 필드)
```
- 세션에도 선택적 필드 `experimentId`가 있습니다. 그 세션을 시작할 때 고른 실험의 ID입니다.
- 이전 기록과의 간격은 저장하지 않고 계산합니다. 그래야 기록을 고치거나 지워도 값이 어긋나지 않습니다. CSV에는 `gap_from_prev_in_group_sec` 열로 들어갑니다.
- 이탈 지속시간 필드는 없습니다(관측하지 않으므로). 1차 버전의 자기보고 소요시간은 `legacy.durationBucket`에만 보존합니다.

## 테스트

```powershell
node --test tests/stats.test.mjs tests/store.test.mjs
node tests/e2e.mjs
```
- 단위 테스트는 마이그레이션, 병합, CSV, 월 경계, 일광절약시간(DST), 인사이트 형식을 확인합니다.
- E2E 테스트는 Playwright가 있어야 실행됩니다. 없으면 `SKIP`을 출력하고 종료 코드 2로 끝납니다(통과로 보지 않습니다). 원탭 기록, 되돌리기, 중복 방지, 복귀 문구, 잠금, 마이그레이션, 오프라인, 모바일 375px를 확인합니다.

## 한계
- 알아차리지 못한 이탈은 기록되지 않습니다. 이 앱은 다른 앱이나 화면 사용을 감시하지 않고, 자동으로 감지하지도 않습니다.
- 브라우저 탭 안에서만 동작하므로, 다른 프로그램을 쓰는 중에 전역 단축키로 기록할 수는 없습니다.
- 여러 기기 간 동기화는 없습니다. JSON 내보내기와 가져오기(병합)로 옮겨야 합니다.

## 프로젝트 구조
```
index.html            화면 (지금 / 보관함 / 패턴 / 데이터)
styles.css            파스텔 핑크 테마, 다크 모드
js/stats.js           통계·인사이트 (순수 함수, Node 테스트 가능)
js/store.js           localStorage 저장, v1→v2 마이그레이션, 내보내기/가져오기
js/app.js             UI 동작
sw.js                 오프라인 지원 (항상 새 파일 확인)
manifest.webmanifest  홈 화면 설치(PWA)
tests/                단위 테스트, 브라우저 E2E 테스트
```
